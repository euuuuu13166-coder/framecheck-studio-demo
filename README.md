# 帧检 FrameCheck Studio

为 Godot 4 开发者整理透明 PNG 动画素材：切分不规则图集、修框、合并、排序、对齐、检查和导出。

在线免费演示：https://euuuuu13166-coder.github.io/framecheck-studio-demo/

## 1.2.0 · 2026-10-30

演示版只处理内置示例；可以编辑、保存示例项目和导出 Godot 工程，打开项目和自有素材导入仅在完整版启用。

## 范围

这不是图像生成器或完整绘画软件。每个项目处理一组动画；不支持多个命名动作、逐帧独立时长或其他引擎专用导出。Godot 自带规则图集动画编辑，帧检的重点在导入前的不规则素材整理。

不上传素材、不自动发送诊断。项目文件包含素材像素，请自行保管。核心测试、浏览器操作和8帧 Godot 示例经过检查，不代表所有素材与环境均适用。尚无付费需求或收入验证。

本仓库发布免费体验及说明，不包含付费交付包。工具与 Godot 无官方合作关系。
